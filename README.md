# 📖 Overview

Job Portal is a full-stack recruitment platform that connects job seekers with recruiters.

The platform enables users to browse job listings, search by keywords, apply for jobs, manage applications, and allows recruiters to post and manage job openings.

Built using React for the frontend, Express.js for the backend, MySQL for database management, and JWT Authentication for secure user access.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/HarshAwasth-i/Job-Portal.git
```

Move into the project

```bash
cd Job-Portal
```

---

## Frontend

```bash
cd client
npm install
npm run dev
```

---

## Backend

```bash
cd server
npm install
npm start
```

---

## Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

DB_HOST=localhost
DB_PORT=3306
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=job_portal

JWT_SECRET=your_secret_key
```
